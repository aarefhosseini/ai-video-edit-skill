# Product contract — 0.1.0 beta

Audience: content creators. Scope: general short-video production and companion images/carousels, from ideation through supplied post-publication analysis. Exclusions: long-form production, publishing, account management. Public product; no Codevo visual defaults.

The creator supplies intent/files and communicates through the agent. The agent prepares the local runtime and handles commands. Target agents: Codex and Claude Code. Target runtime OSes: macOS, Windows, Linux. Persian/RTL and English are first-class requirements. Document actual compatibility separately.

The first exchange establishes content, audience, destination, material/brand/reference needs and guided/automatic mode. Subsequent questions depend on missing information, not a repeated questionnaire. Output aspect ratio and safe-region assumptions follow the actual destination.

Use available host reasoning, search, browser, audiovisual and generative capabilities when relevant. No separate paid API. Local media scripts make no external requests. Installed host AI/generative features may still have their own account limits; never claim their execution is offline or universally free. Prefer truthful real captures. Request missing essential assets; if declined, create an appropriate illustration or restructure without false evidence.

Quality goals: fewer revisions, stronger framing, natural color/retouch, clean editing, clear narrative and attention. Viral performance is an optimization goal, not a guaranteed product outcome. Reference success needs observable evidence.

All production phases have workflow guidance from v0.1. Scripted operations cover cut assembly, simple face/media composition, captions, frame previews, silent motion samples, export, verification, and explicit-allowlist packaging. Host-dependent operations such as browser recording, speech recognition, AI image/video generation and perceptual listening require actually available tools. Advanced editorial designs use project-local code.

Default deliverables: MP4, review report, editable code/timeline package; SRT/cover/caption/carousel as relevant. Native editing-app formats are outside the default. Guided mode requires complete-preview approval; automatic mode works within agreed limits. Preserve locked masters unless the user reopens their contract. Keep a single current project record.

Release confidence: technical behavioral tests, synthetic public example, skill schema validation, installer checks, and honest compatibility status. Before claiming stable broad support, complete the host/OS and creator trials listed in release-validation.md. The maintainer handles GitHub publication and release decisions.
