# Video Edit

اسکیل رایگان و متن‌باز برای ساخت و تدوین ویدیوهای کوتاه در Codex و Claude Code.

کاربر فایل‌ها، مقصد انتشار و نمونه‌های دلخواهش را می‌دهد. عامل سؤال‌های لازم را می‌پرسد، نمونه‌های مرتبط را بررسی می‌کند، طرح تدوین و پیش‌نمایش همهٔ بخش‌ها را می‌سازد و خروجی محلی تحویل می‌دهد. آماده‌سازی ابزارها و اجرای فرمان‌ها وظیفهٔ عامل است.

نسخهٔ فعلی: **۰٫۱٫۰ بتا**. موتور محلی آزمایش دارد؛ دسترسی به مرورگر، ضبط صفحه، تحلیل صوت و تولید تصویر به ابزارهای محیط میزبان وابسته است. وضعیت تست هر محیط در [جدول سازگاری](compatibility.md) آمده است.

## شروع

ریپوی اسکیل را در عامل باز کن و بنویس:

> اسکیل video-edit این ریپو را برای Codex یا Claude Code در پروژهٔ انتخابی من نصب کن. ابزارهای محلی موردنیاز را آماده کن. بعد دربارهٔ محتوایی که می‌خواهم بسازم، مقصد انتشار و حالت مرحله‌ای یا خودکار بپرس. از API پولی جداگانه استفاده نکن.

بعد از نصب در Codex از `$video-edit` و در Claude Code از `/video-edit` استفاده کن. درخواست طبیعی برای تدوین ویدیوی کوتاه هم می‌تواند اسکیل را فعال کند. نصب‌کننده نسخهٔ موجود را بدون بازبینی جایگزین نمی‌کند.

نمونهٔ درخواست:

> از این برداشت‌ها و اسکرین‌رکورد محصول، ریلز بساز. قاب‌بندی را از این مرجع الهام بگیر؛ چهره و صدایم طبیعی بماند. زیرنویس فارسی خوانا می‌خواهم. تمام بخش‌ها و حرکت‌ها را قبل از خروجی نهایی نشان بده. رنگ‌های برند من سرمه‌ای و سفید گرم است.

## قابلیت‌ها

- ایده، تحلیل مرجع، سناریو، راهنمای ضبط، انتخاب برداشت و تدوین.
- برش دقیق، تنظیم سرعت با حفظ زیر و بمی، اصلاح اختیاری رنگ و صدا.
- قاب‌بندی چهره و تصویر، نمایش بخش مرتبط ضبط واقعی، زیرنویس فارسی و انگلیسی، پس‌زمینه و پیش‌نمایش حرکت.
- کاور، کپشن، کاروسل و تحلیل داده‌های واقعیِ ارائه‌شده پس از انتشار.
- حفظ دقیق صدای مستر تأییدشده هنگام مونتاژ و کنترل فایل خروجی.

**حالت مرحله‌ای:** پیش‌نمایش همهٔ بخش‌ها و ترانزیشن‌ها ارائه می‌شود؛ رندر نهایی پس از تأیید همان طرح است.

**حالت خودکار:** عامل در محدودهٔ خواسته و اجازه‌های مشخص‌شده کار را جلو می‌برد و تصمیم‌های مهم و محدودیت‌ها را گزارش می‌دهد.

بهبود هوک، وضوح، ریتم و قابلیت اشتراک‌گذاری هدف است؛ وایرال‌شدن تضمین نمی‌شود. ویدیوی بلند، انتشار خودکار و مدیریت پیج در دامنهٔ این اسکیل نیستند.

## ابزار و هزینه

عامل از Python و FFmpeg محلی استفاده می‌کند؛ کاربر عادی لازم نیست فرمان بنویسد. برای نصب اولیهٔ بسته‌ها ممکن است اینترنت لازم باشد. API پولی مستقلی لازم نیست؛ هزینه و محدودیت حساب خود Codex یا Claude همچنان متعلق به همان میزبان است.

کد برای macOS، Windows و Linux نوشته شده است. پشتیبانی قطعی هر ترکیب پس از تست همان محیط اعلام می‌شود. اسکیل به‌تنهایی امکان ضبط صفحه یا تولید تصویر را به میزبان اضافه نمی‌کند؛ عامل قابلیت موجود را تشخیص می‌دهد و جایگزین مناسب یا کمبود لازم را توضیح می‌دهد.

روتوش پیشرفته، ردیابی ماسک، میکس صدا و حرکت اختصاصی به اجرای متناسب با پروژه نیاز دارند؛ همهٔ این‌ها کلید آماده در موتور سادهٔ همراه نیستند. مسیر تصمیم‌گیری و بررسی آن‌ها در مرجع تدوین آمده است.

## تحویل

پیش‌فرض: ویدیوی MP4، گزارش بررسی و پروژهٔ کدنویسی‌شده با فایل زمان‌بندی و دارایی‌های منتخب. زیرنویس SRT، کاور و کپشن متناسب با درخواست اضافه می‌شوند. پروژهٔ قابل‌ویرایش این نسخه، پروژهٔ کد/زمان‌بندی است؛ خروجی بومی Premiere یا CapCut ادعا نشده است.

نماهای واقعی و تصویرسازی از هم مشخص می‌شوند. تصویر تولیدشده، شاهد پرداخت، قابلیت واقعی نرم‌افزار یا نتیجهٔ مشتری نیست. اگر نمای ضروری کم باشد، ابتدا درخواست تکمیل می‌شود؛ سپس با مواد موجود، تصویرسازی مناسب یا ساختار ساده‌تر، خروجی صادقانه آماده می‌شود.

اسکریپت‌های همراه فایل‌ها را محلی پردازش می‌کنند و API یا آپلودی ندارند. خود مدل میزبان همچنان اطلاعات داده‌شده را پردازش می‌کند؛ ادعای اجرای کاملاً آفلاین کل گفت‌وگو نداریم. نمونه‌های عمومی ریپو مستقل و آزمایشی‌اند. فونت، موسیقی و دارایی دیگران مجوز خودشان را دارند.
