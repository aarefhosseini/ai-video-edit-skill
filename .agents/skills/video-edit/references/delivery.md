# Companion assets and delivery

## Covers and carousels

Ask for or derive the destination, title, promise, and key visual from the real brief. Use a representative real frame/project detail or an explicitly chosen illustration. Keep title and face readable under the destination's relevant crops; check the exported image in each selected ratio. Use actual brand inputs; no default Codevo assets.

Create editable text/vector or code-based layers when appropriate. Render final typography with real fonts, especially Persian. Generate decoration with available native tools when useful; avoid asking image generation to be the only source of exact final Persian text. For a carousel, maintain an information progression and check every slide for one clear idea and mobile readability.

## Caption and CTA

Write naturally in the user's language and tone. Align the promise with the actual demonstrated feature. Use a CTA only if it fits the goal and the offered file/sample is ready. “Comment for the source” requires an available authorized source package; a prepared caption doesn't establish an automatic DM system. No algorithm folklore or invented results.

## Editable package

Default video delivery: MP4, review report, relative-path code/timeline project. Add SRT if captions were requested, and cover/caption/carousel outputs appropriate to the brief. Native Premiere/DaVinci/CapCut interchange is optional and must be tested in the target editor before claiming support.

Include selected sanitized clips, approved master, required assets with redistribution rights, dependencies, exact rerender command, and source fingerprints. Exclude unused takes, caches, `.venv`, account sessions and private data. Include fonts only when their redistribution license permits it; otherwise document how the agent resolves an installed user font.

`media.py package PROJECT --output FILE.zip` packages an explicit allowlist in `project.json`, verifies files exist, rejects paths/symlinks outside the project, and records hashes. The agent reviews this list before use; a script can't establish semantic privacy or asset rights.

Finish locally. The creator decides when to publish; no account operations or external messages are part of this skill.
