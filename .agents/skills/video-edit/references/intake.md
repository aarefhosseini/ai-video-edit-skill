# Project intake

Ask about the content before choosing tools or a template. Prior answers and a supplied approved brief take precedence. Group missing questions into one short message; avoid a mandatory 26-question questionnaire per video.

## Essential decisions

1. What are we making, for whom, and what should viewers understand/do?
2. Destination and placement: platform, organic/ad, feed/story, presentation, language, approximate duration. Inspect current platform requirements when relevant; choose dimensions from this project, not a permanent safe-zone chart.
3. Source state: raw footage, selected takes, locked master, screen recording, real site/app, reference links. What may change: cuts, speed, speech, retouch, color, captions, background, music?
4. Mode: guided complete-preview approval or automatic execution within the brief.
5. Direction: reference examples, desired feeling, typography/color/background/logo if any, negative preferences. Optional cover title/text and CTA. Infer reasonable optional defaults and state them.

Ask follow-ups only for consequential gaps: recording permission, a missing required shot, an uncertain word/claim, use of a particular person's likeness/voice, music/asset rights, or shipping private content to another service.

## Working contract

Record selected master and fingerprint; current selected revision; default local processing; allowed source edits; whether host-native generative tools may receive selected media; requested deliverables; current approval state. The host model's normal processing is distinct from an additional third-party upload. A request for a final file alone does not authorize a new external upload.

For a locked master, preserve everything not explicitly reopened. A user may approve new captions after an earlier no-caption brief: update the current contract and keep that project-specific decision out of global skill policy.

## Missing material

Inventory scenes before expensive production. Classify missing material as evidence, creator footage, or decoration. Request essential footage clearly with framing, spoken text, duration, and suggested action. If it remains unavailable, choose an illustration for decoration, narration with real available footage, or a shorter truthful edit. Record gaps that still affect completeness. A generated UI or customer result is not a substitute for evidence.
