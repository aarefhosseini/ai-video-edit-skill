## 0.1.0-beta.1 — 2026-10-13

First public beta.

- Codex and Claude Code project installers; English and Persian guidance.
- Brief, references, scripts, recording guidance, editing and delivery workflow.

Known limits: full live agent workflows and an independent creator trial remain pending. Browser recording, transcription, listening and generation require the host agent to expose those tools. No guaranteed virality or native editing-app project export.
